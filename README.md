

# Data Quality Management and Insights Dashboard

## Project Overview
This project focuses on cleaning and analysing a bike buyers dataset using Microsoft Excel. The objective was to improve data consistency, summarise customer information, and identify patterns related to bike purchases.

## Tools Used
- Microsoft Excel
- Excel Functions
- Pivot Tables
- Charts and Dashboards

## Work Performed
- Cleaned and standardised raw customer data.
- Created age brackets using Excel formulas.
- Analysed average income by gender and bike purchase.
- Examined bike purchases across commute distances and age groups.
- Created Pivot Tables and visualisations to summarise findings.

## Files
- `Bike_Buyers_Analysis.xlsx` – Excel workbook containing the dataset, cleaned data, Pivot Tables and dashboard.

## Key Learning
Gained practical experience in data cleaning, data organisation, Pivot Table analysis and dashboard creation.
